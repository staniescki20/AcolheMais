💙 AcolheMais - Cuidado e Vínculo em Saúde

📌 Sobre o Projeto

O AcolheMais é uma aplicação web desenvolvida como solução para o Desafio da disciplina de Desenvolvimento Web. Baseado no tema "Cuidado em Saúde", o projeto visa promover um atendimento humanizado, facilitando o primeiro contato do paciente com a unidade de saúde, organizando seus cuidados diários e fortalecendo o vínculo entre usuários e profissionais.

O foco principal da aplicação é o acolhimento, utilizando interações dinâmicas para orientar o paciente de forma clara, empática e acessível.

🛠️ Tecnologias Utilizadas

Para atender aos requisitos acadêmicos, este projeto foi construído sem o uso de frameworks de front-end ou back-end. Utilizamos apenas tecnologias nativas da web:

HTML5: Estruturação semântica das páginas.

CSS3: Estilização, layout responsivo e design visual.

JavaScript : Lógica de programação, manipulação do DOM e armazenamento local (localStorage) para tornar o site dinâmico.

⚙️ Funcionalidades e Estrutura das Telas

O site é composto por 4 áreas principais, divididas entre os membros da equipe:

Página Inicial (Home): Apresentação do portal, mensagens de acolhimento e navegação principal.

Triagem Virtual (Interação JS 1): Um formulário interativo de autoavaliação de sintomas. O sistema calcula a prioridade do atendimento e exibe orientações personalizadas na tela.

Meus Cuidados (Interação JS 2): Um gerenciador de medicamentos e consultas (estilo To-Do List). Utiliza o localStorage do navegador para salvar as informações inseridas pelo paciente, simulando um banco de dados local (CRUD).

Mural de Feedback (Interação JS 3): Um espaço para o paciente relatar sua experiência. Ao enviar a mensagem, o JavaScript cria e exibe dinamicamente um novo "card" de depoimento na tela.

🚀 Como Executar o Projeto

Como o projeto utiliza apenas tecnologias de front-end nativas, não é necessário instalar nenhum servidor ou dependência. Para testar:

Extraia o arquivo .zip do projeto.

Abra a pasta descompactada.

Dê um clique duplo no arquivo index.html para abri-lo em qualquer navegador web moderno (Google Chrome, Firefox, Edge, etc.).
